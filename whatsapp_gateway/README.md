# OmniPrice — Autonomous Price Intelligence Engine

OmniPrice is an autonomous retail reasoning and multi-platform price arbitrage engine developed by **OnePersonAI**. It bypasses modern retail bot walls, extracts verified selling prices across Indian marketplaces, and delivers real-time forecasting with 24/7 background WhatsApp alerts.

## Key Capabilities
- **Multi-Store Corridor:** Queries Flipkart, Amazon India, Myntra, Ajio, Tata CLiQ, JioMart, and Nykaa simultaneously.
- **Autonomous AI Agent:** Multi-tier entity resolution powered by Groq and OpenRouter.
- **Dynamic 7-Day Trajectory:** Micro-trend forecasting with historical floor spread analysis.
- **24/7 WhatsApp Radar Daemon:** Background monitor dispatching instant price-drop alerts.
